# Legacy v1 — superseded, retained for audit history

This directory preserves the previous analysis code, data, model outputs and manuscript used during development. It is **not** the evidence base for the final v2 headline claims.

The supplied hostile review identified that the v1 physical feasibility mask used realized target-time connectivity. That created future-information leakage and inflated the apparent post-processing gain. The v2 pipeline fixes this by predicting future connectivity and forbidding target-time realization arrays from the feasibility projection.

Retain v1 only for provenance, debugging and comparison. Do not cite v1 headline classification improvements as final scientific results.
