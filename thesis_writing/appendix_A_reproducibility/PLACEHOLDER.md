## A.1 Reproducibility Statement
All results in this thesis are fully reproducible given the instructions below.

## A.2 Environment Setup
```bash
# Clone the repository
git clone https://github.com/mtk1793/Review-Papers.git
cd Review-Papers/capsim_sim

# Create conda environment
conda env create -f environment.yml
conda activate capsim_sim

# Or use pip
pip install -r requirements.txt
```

## A.3 Data Sources
- **OPSD data:** January 2019, Nova Scotia Power territory
  - Download from: https://open power system data.org/
  - Preprocessed: included in `capsim_sim/data/opsd_2019.csv`
- **IEEE test systems:** IEEE 39-bus (base case), IEEE 118-bus
  - Included in `capsim_sim/capsm/grid/`
- **EV charging profiles:** IEEE 2030.1.2
  - Included in `capsim_sim/data/ev_profiles.csv`

## A.4 Running Experiments

### Full experiment suite (all 6 controllers, all 6 scenarios):
```bash
cd capsim_sim
pytest -q                    # Run all 52 tests (validates environment)
python scripts/run_all_experiments.py  # Generates all results
```

### Individual controller testing:
```bash
python -m capsm.run --controller caps --scenario normal
python -m capsm.run --controller system1 --scenario p1
python -m capsm.run --controller system2 --scenario ev_stress
```

### Generating thesis figures:
```bash
python scripts/generate_thesis_artifacts.py
```

## A.5 Hardware Requirements
- Minimum: 8 GB RAM, 4 CPU cores
- For CHIL: OPAL-RT OP5600 or equivalent with 4 cores

## A.6 Expected Runtime
- Full SIL experiment suite: ~2 hours on standard laptop
- PIL: ~30 minutes
- CHIL: requires OPAL-RT hardware (~4 hours)

## A.7 Random Seeds
All experiments use seed=42 by default. For sensitivity analysis, seeds 0–4 were tested.

## A.8 Figure Reproduction
All thesis figures are generated by scripts in `capsim_sim/scripts/`. To reproduce:
```bash
python scripts/generate_thesis_artifacts.py --output_dir ../thesis_writing/figures/
```
